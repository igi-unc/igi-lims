Import QC

Upload one export file from an instrument. The file is kept with the tubes it describes, and each value you confirm is written to the tube with a link back to the file.

Supported: Qubit 4 (CSV/XLSX), NanoDrop One (CSV), Agilent TapeStation (XML export from TapeStation Analysis), Countess 3 / 3 FL (CSV). Name samples on the instrument with the full tube ID and the rows will match themselves.
