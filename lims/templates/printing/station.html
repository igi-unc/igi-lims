Setting up this computer

Windows printer (USB), done once:

  1. Install Brady's M611 driver, plug the printer in by USB, and make BradyPrinter M611 the default printer (Windows Settings, Printers & scanners; turn off "Let Windows manage my default printer"). Leave the driver's orientation and size settings alone; Chrome decides them.
  2. Create a Chrome shortcut with silent printing switched on, pointing at this page:
    "C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk-printing --app={{ request.url_root.rstrip('/') }}{{ url_for('printing.station') }}
    Put it in the Startup folder (Win+R, shell:startup). Close every other Chrome window before its first start, or the switch is ignored.
  3. Log in as the station account, click Test print (no dialog should appear), then Start printing. After a restart it starts printing by itself.

Bluetooth (Chrome or Edge on a computer or Android tablet): choose Bluetooth under Settings, then Connect printer once per page load. Labels are drawn for {{ stock.part }}, {{ stock.width_in }} × {{ stock.height_in }} in.
