Printer

Windows printer (USB) Bluetooth

Prints through the Brady driver installed on this computer. Set it up once:

  1. Install Brady's M611 driver, plug the printer in by USB, and make BradyPrinter M611 the default printer (Windows Settings, Printers & scanners; turn off "Let Windows manage my default printer"). In the printer's preferences, choose the {{ stock.part }} label size and no margins.
  2. Start Chrome from a shortcut with silent printing switched on, pointing at this page:
    "C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk-printing --app={{ request.url_root.rstrip('/') }}{{ url_for('printing.station') }}
    Put the shortcut in the Startup folder (Win+R, shell:startup) so it opens after a restart. Close every other Chrome window before the first start, or the switch is ignored.
  3. Click Test print. If a print dialog appears, Chrome was not started with the switch.
