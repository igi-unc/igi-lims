Print station

Leave this page open on the computer next to the Brady printer. It collects queued jobs every few seconds and prints them in order, each job starting with a header label that names who asked for it. Labels are drawn for {{ stock.part }}: {{ stock.width_in }} × {{ stock.height_in }} in.

Printer

Windows printer (USB) Bluetooth

Prints through the Brady driver installed on this computer. Set it up once:

  1. Install Brady's M611 driver, plug the printer in by USB, and make BradyPrinter M611 the default printer (Windows Settings, Printers & scanners; turn off "Let Windows manage my default printer").
  2. In the printer's Printing preferences, set the label (paper) size to {{ stock.width_in }} in wide × {{ stock.height_in }} in long, the {{ stock.part }} stock: labels leave the printer with the notch on the left and the long ({{ stock.width_in }} in) edge at the top, so {{ stock.width_in }} in runs across the roll and {{ stock.height_in }} in along it. Orientation portrait, no margins. If the driver offers the size only as {{ stock.height_in }} × {{ stock.width_in }}, that is the wrong way round: a label then prints sideways or across two labels.
  3. Start Chrome from a shortcut with silent printing switched on, pointing at this page:
    "C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk-printing --app={{ request.url_root.rstrip('/') }}{{ url_for('printing.station') }}
    Put the shortcut in the Startup folder (Win+R, shell:startup) so it opens after a restart. Close every other Chrome window before the first start, or the switch is ignored.
  4. Click Test print. If a print dialog appears, Chrome was not started with the switch.

Calibrate prints the alignment label once in each layout, marked LAYOUT A to D: A = {{ stock.width_in }} × {{ stock.height_in }} as drawn, B = upside down, C = upright page turned left, D = upright page turned right. All four go out as one 4-page print (in a print dialog you will see four pages). Pick the one that comes out on a single label, complete and the right way up, and choose that layout above.

Alignment test prints one label with a border and TOP / LEFT / RIGHT / BOTTOM marks. If it comes out wrong, photograph it still attached to the roll, as it leaves the printer.
